> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aba **Metas** em que o admin cria metas (empresa, pessoa ou grupo; automáticas ou manuais; prazo único ou recorrente) e acompanha num painel com ritmo semanal, kanban de etapas próprias, barra de ondas roxas e análise diária da Lume; o usuário vê as próprias metas e as da empresa.

**Architecture:** Tabelas e regras de acesso no Supabase (migração `20261017120000_goals.sql`); o progresso é calculado no banco por RPC (`goals_progress`) com os dados reais; o selo de situação e o esperado são calculados por um único módulo TypeScript puro (`src/lib/goals/model.ts`) usado pela tela e pela rotina diária; a rotina diária (`/api/public/hooks/goals-tick`, chamada pelo `pg_cron`) grava fotos, renova recorrências e pede à Lume a análise, salva em `goal_insights`.

**Tech Stack:** React 19 + TanStack Start/Router, Tailwind v4, Supabase (Postgres + RLS + RPC), Vitest + Testing Library + PGlite, zod, lucide-react.

**Spec:** `docs/superpowers/specs/2026-10-16-metas-design.md`

## Global Constraints

- Migração **aditiva e reexecutável** (`IF NOT EXISTS`, `CREATE OR REPLACE`, `DO $$ … EXCEPTION WHEN duplicate_object`); rodar duas vezes não pode falhar.
- Permissões novas exatamente: `goals.view` (rótulo "Ver metas", padrão: todos) e `goals.manage` (rótulo "Gerenciar metas", padrão: só admin).
- Indicadores (valores de `metric`) exatamente: `receita_fechada`, `vendas_fechadas`, `leads_novos`, `taxa_conversao`, `orcamentos_criados`, `orcamentos_enviados`, `conversas_respondidas`, `tempo_primeira_resposta`, `compromissos_concluidos`.
- Selos exatamente: `concluida`, `no_ritmo` (≥ 90% do esperado), `em_risco` (70%–90%), `atrasada` (< 70%), `sem_dados`, `encerrada`.

- Datas de período em fuso `America/Sao_Paulo`; semanas de segunda a domingo.
- **Sem modelos prontos** de meta e **sem etapas pré-criadas**.
- Visual: linguagem do dashboard (`lume-dashboard`), roxo `#7C3AED` / `#A855F7` / `#B594FF`, formulários com `lq-black lq-panel`, `quote-form-input`, `lq-primary`/`lq-secondary`.
- Mobile < 768 px usa as primitivas existentes `MobileSections`, `MobileRail`, `SegmentedTabs` (`src/components/layout/`).
- Toda animação só com `transform`/`opacity` e respeitando `prefers-reduced-motion`.

```ts
 * Metas — regras puras. Tela e rotina diária usam este módulo, então o
 * "esperado até hoje", as semanas e o selo têm uma única definição.
 * Datas sempre como "YYYY-MM-DD" no fuso America/Sao_Paulo.

const DAY = 86_400_000;
const toTime = (date: string) => Date.parse(`${date}T00:00:00Z`);
const fromTime = (time: number) => new Date(time).toISOString().slice(0, 10);

export function daysBetween(a: string, b: string): number {
  return Math.round((toTime(b) - toTime(a)) / DAY) + 1;
}

export function todayInSaoPaulo(now: Date = new Date()): string {
  return new Intl.DateTimeFormat("en-CA", {
    timeZone: "America/Sao_Paulo",
    year: "numeric",
    month: "2-digit",
    day: "2-digit",
  }).format(now);
}

export function expectedToDate(
  target: number,
  period: GoalPeriod,
  today: string,
  lowerIsBetter: boolean,
): number {
  if (lowerIsBetter) return target;
  if (today < period.startsOn) return 0;
  if (today >= period.endsOn) return target;
  const elapsed = daysBetween(period.startsOn, today);
  const total = daysBetween(period.startsOn, period.endsOn);
  return Math.round(((target * elapsed) / total) * 100) / 100;
}

export function goalStatus(input: {
  value: number | null;
  expected: number;
  target: number;
  lowerIsBetter: boolean;
  period: GoalPeriod;
  today: string;
}): GoalStatus {
  const { value, expected, target, lowerIsBetter, period, today } = input;
  const ended = today > period.endsOn;
  const hasData = value !== null && (lowerIsBetter || value > 0);
  if (!hasData) {
    if (lowerIsBetter) return "sem_dados";
    const third = daysBetween(period.startsOn, period.endsOn) / 3;
    if (!ended && daysBetween(period.startsOn, today) <= third) return "sem_dados";
    return ended ? "encerrada" : "atrasada";
  }
  const v = value as number;
  if (lowerIsBetter) {
    if (ended) return v <= target ? "concluida" : "encerrada";
    if (v <= target) return "no_ritmo";
    if (v <= target / 0.7 && v <= target * 1.3) return "em_risco";
    return "atrasada";
  }
  if (v >= target) return "concluida";
  if (ended) return "encerrada";
  if (expected <= 0) return "no_ritmo";
  const ratio = v / expected;
  if (ratio >= 0.9) return "no_ritmo";
  if (ratio >= 0.7) return "em_risco";
  return "atrasada";
}

export function splitWeeks(period: GoalPeriod, target: number, lowerIsBetter: boolean) {
  const total = daysBetween(period.startsOn, period.endsOn);
  const weeks: Array<{ startsOn: string; endsOn: string; expected: number }> = [];
  let cursor = toTime(period.startsOn);
  const end = toTime(period.endsOn);
  while (cursor <= end) {
    const weekday = (new Date(cursor).getUTCDay() + 6) % 7; // 0 = segunda
    const weekEnd = Math.min(cursor + (6 - weekday) * DAY, end);
    const days = Math.round((weekEnd - cursor) / DAY) + 1;
    weeks.push({
      startsOn: fromTime(cursor),
      endsOn: fromTime(weekEnd),
      expected: lowerIsBetter ? target : Math.round(((target * days) / total) * 100) / 100,
    });
    cursor = weekEnd + DAY;
  }
  return weeks;
}

export function buildProgress(goal: Goal, raw: GoalProgressRaw, today: string): GoalProgress {
  const period = { startsOn: raw.periodStart, endsOn: raw.periodEnd };
  const expected = expectedToDate(goal.target, period, today, goal.lowerIsBetter);
  const status = goalStatus({ value: raw.value, expected, target: goal.target, lowerIsBetter: goal.lowerIsBetter, period, today });
  const planned = splitWeeks(period, goal.target, goal.lowerIsBetter);
  const weeks: GoalWeek[] = planned.map((week) => {
    const actual = raw.weeks.find((w) => w.startsOn === week.startsOn)?.actual ?? null;
    const weekPeriod = { startsOn: week.startsOn, endsOn: week.endsOn };
    return {
      ...week,
      actual,
      status:
        actual === null
          ? null
          : goalStatus({
              value: actual,
              expected: expectedToDate(week.expected, weekPeriod, today, goal.lowerIsBetter),
              target: week.expected,
              lowerIsBetter: goal.lowerIsBetter,
              period: weekPeriod,
              today,
            }),
    };
  });
  const value = raw.value ?? 0;
  const pct = goal.lowerIsBetter
    ? raw.value === null
      ? 0
      : Math.min(100, (goal.target / Math.max(value, 0.0001)) * 100)
    : Math.min(100, (value / goal.target) * 100);
  return { ...raw, expected, status, pct: Math.round(pct * 100) / 100, weeks };
}

export function validateGoalDraft(draft: GoalDraft): string[] {
  const errors: string[] = [];
  if (!draft.name.trim()) errors.push("Dê um nome para a meta.");
  if (draft.name.trim().length > 120) errors.push("O nome pode ter até 120 caracteres.");
  if (!(draft.target > 0)) errors.push("O alvo precisa ser maior que zero.");
  if (draft.measure === "automatica" && !draft.metric) errors.push("Escolha o que o sistema vai medir.");
  if (draft.measure === "manual" && !draft.unit.trim()) errors.push("Diga a unidade (ex.: visitas).");
  if (draft.measure === "manual" && draft.unit.trim().length > 24) errors.push("A unidade pode ter até 24 caracteres.");
  if (draft.scope === "pessoa" && draft.memberIds.length !== 1) errors.push("Escolha a pessoa da meta.");
  if (draft.scope === "grupo" && draft.memberIds.length < 2) errors.push("Um grupo precisa de pelo menos 2 pessoas.");
  if (!draft.startsOn) errors.push("Escolha a data de início.");
  if (draft.deadline === "unico") {
    if (!draft.endsOn) errors.push("Escolha a data de fim.");
    else if (draft.endsOn < draft.startsOn) errors.push("A data de fim precisa ser depois do início.");
  }
  return errors;
}

export function formatGoalValue(
  value: number | null,
  goal: Pick<Goal, "measure" | "metric" | "unit">,
): string {
  if (value === null || Number.isNaN(value)) return "—";
  if (goal.measure === "manual") return `${dec.format(value)} ${goal.unit ?? ""}`.trim();
  const kind = goal.metric ? METRICS[goal.metric].kind : "count";
  if (kind === "brl") return brl.format(value).replace(/ /g, " ");
  if (kind === "pct") return `${dec.format(value)}%`;
  if (kind === "min") return `${dec.format(value)} min`;
  return dec.format(value);
}
```

```sql
CREATE OR REPLACE FUNCTION public.goals_can_manage(_company uuid)
RETURNS boolean LANGUAGE plpgsql STABLE SECURITY DEFINER SET search_path = public AS $$
BEGIN
  RETURN _company IS NOT NULL AND _company = public.current_company_id()
    AND (public.has_role(auth.uid(), _company, 'admin') OR public.team_has_permission('goals.manage'));
END; $$;

CREATE OR REPLACE FUNCTION public.goals_can_see(_goal uuid)
RETURNS boolean LANGUAGE plpgsql STABLE SECURITY DEFINER SET search_path = public AS $$
DECLARE g public.goals;
BEGIN
  SELECT * INTO g FROM public.goals WHERE id = _goal;
  IF NOT FOUND OR g.company_id IS DISTINCT FROM public.current_company_id() THEN RETURN false; END IF;
  IF public.goals_can_manage(g.company_id) THEN RETURN true; END IF;
  RETURN public.team_has_permission('goals.view') AND (g.scope = 'empresa' OR EXISTS (
    SELECT 1 FROM public.goal_members m WHERE m.goal_id = g.id AND m.user_id = auth.uid()));
END; $$;

CREATE OR REPLACE FUNCTION public.goals_day_start(_day date)
RETURNS timestamptz LANGUAGE sql IMMUTABLE AS $$
  SELECT (_day::timestamp AT TIME ZONE 'America/Sao_Paulo');
$$;

CREATE OR REPLACE FUNCTION public.goals_period_bounds(_recurrence text, _starts date, _ends date, _day date)
RETURNS TABLE (starts_on date, ends_on date) LANGUAGE sql IMMUTABLE AS $$
  SELECT
    CASE _recurrence
      WHEN 'semanal' THEN greatest(_starts, date_trunc('week', _day)::date)
      WHEN 'mensal' THEN greatest(_starts, date_trunc('month', _day)::date)
      ELSE _starts END,
    CASE _recurrence
      WHEN 'semanal' THEN (date_trunc('week', _day) + interval '6 days')::date
      WHEN 'mensal' THEN (date_trunc('month', _day) + interval '1 month' - interval '1 day')::date
      ELSE _ends END;
$$;

CREATE OR REPLACE FUNCTION public.goals_open_first_period()
RETURNS trigger LANGUAGE plpgsql SECURITY DEFINER SET search_path = public AS $$
BEGIN
  INSERT INTO public.goal_periods (goal_id, starts_on, ends_on)
  SELECT NEW.id, b.starts_on, b.ends_on FROM public.goals_period_bounds(NEW.recurrence, NEW.starts_on, NEW.ends_on, NEW.starts_on) b
  ON CONFLICT (goal_id, starts_on) DO NOTHING;
```

```sql
-- ---------- 5. Indicadores e progresso ----------
-- "Agora" das metas: o relógio do banco, ou uma data fixa em testes
-- (SELECT set_config('lume.goals_now', '2026-10-31T12:00:00-03:00', false)).
CREATE OR REPLACE FUNCTION public.goals_now()
RETURNS timestamptz LANGUAGE sql STABLE AS $$
  SELECT coalesce(nullif(current_setting('lume.goals_now', true), '')::timestamptz, now());
$$;

-- Cálculo bruto: lê leads/orçamentos/mensagens/agenda ignorando RLS, então
-- NÃO pode ser chamado pela API. Só as RPCs abaixo (que conferem acesso) usam.
-- _users NULL = toda a empresa (inclui registros sem responsável).
CREATE OR REPLACE FUNCTION public.goals_metric_raw(_company uuid, _metric text, _from timestamptz, _to timestamptz, _users uuid[])
RETURNS numeric LANGUAGE plpgsql STABLE SECURITY DEFINER SET search_path = public AS $$
DECLARE v numeric; n numeric; d numeric;
BEGIN
  IF _metric = 'receita_fechada' THEN
    SELECT sum(l.closed_value) INTO v FROM leads l
    WHERE l.company_id = _company AND l.status = 'fechado' AND l.closed_at >= _from AND l.closed_at < _to
      AND (_users IS NULL OR l.assigned_to = ANY (_users));
  ELSIF _metric = 'vendas_fechadas' THEN
    SELECT count(*) INTO v FROM leads l
    WHERE l.company_id = _company AND l.status = 'fechado' AND l.closed_at >= _from AND l.closed_at < _to
      AND (_users IS NULL OR l.assigned_to = ANY (_users));
  ELSIF _metric = 'leads_novos' THEN
    SELECT count(*) INTO v FROM leads l
    WHERE l.company_id = _company AND l.created_at >= _from AND l.created_at < _to
      AND (_users IS NULL OR l.assigned_to = ANY (_users));
  ELSIF _metric = 'taxa_conversao' THEN
    n := public.goals_metric_raw(_company, 'vendas_fechadas', _from, _to, _users);
    d := public.goals_metric_raw(_company, 'leads_novos', _from, _to, _users);
    v := CASE WHEN d > 0 THEN round(n * 100.0 / d, 1) END;
  ELSIF _metric = 'orcamentos_criados' THEN
    SELECT count(*) INTO v FROM quotes q LEFT JOIN leads l ON l.id = q.lead_id
    WHERE q.company_id = _company AND q.created_at >= _from AND q.created_at < _to
      AND (_users IS NULL OR l.assigned_to = ANY (_users));
  ELSIF _metric = 'orcamentos_enviados' THEN
    SELECT count(*) INTO v FROM quotes q LEFT JOIN leads l ON l.id = q.lead_id
    WHERE q.company_id = _company AND q.status <> 'rascunho'
      AND coalesce(q.sent_at, q.created_at) >= _from AND coalesce(q.sent_at, q.created_at) < _to
      AND (_users IS NULL OR l.assigned_to = ANY (_users));
  ELSIF _metric = 'conversas_respondidas' THEN
    SELECT count(DISTINCT c.id) INTO v FROM conversations c JOIN leads l ON l.id = c.lead_id
    WHERE c.company_id = _company AND (_users IS NULL OR l.assigned_to = ANY (_users))
      AND EXISTS (SELECT 1 FROM messages m WHERE m.conversation_id = c.id AND m.role = 'agent' AND m.at >= _from AND m.at < _to);
  ELSIF _metric = 'tempo_primeira_resposta' THEN
    SELECT round(avg(extract(epoch FROM (fa.at - fl.at)) / 60)::numeric, 1) INTO v
    FROM conversations c JOIN leads l ON l.id = c.lead_id
    CROSS JOIN LATERAL (SELECT min(m.at) AS at FROM messages m WHERE m.conversation_id = c.id AND m.role = 'lead') fl
    CROSS JOIN LATERAL (SELECT min(m.at) AS at FROM messages m WHERE m.conversation_id = c.id AND m.role = 'agent' AND m.at >= fl.at) fa
    WHERE c.company_id = _company AND fl.at >= _from AND fl.at < _to AND fa.at IS NOT NULL
      AND (_users IS NULL OR l.assigned_to = ANY (_users));
  ELSIF _metric = 'compromissos_concluidos' THEN
    IF EXISTS (SELECT 1 FROM information_schema.columns WHERE table_schema = 'public' AND table_name = 'visits' AND column_name = 'owner_id') THEN
      EXECUTE 'SELECT count(*) FROM public.visits WHERE company_id = $1 AND status = ''concluida''
               AND scheduled_at >= $2 AND scheduled_at < $3 AND ($4 IS NULL OR owner_id = ANY ($4))'
        INTO v USING _company, _from, _to, _users;
    END IF;
  END IF;
  RETURN v;
END; $$;

CREATE OR REPLACE FUNCTION public.goals_value(_goal uuid, _from timestamptz, _to timestamptz, _users uuid[])
RETURNS numeric LANGUAGE plpgsql STABLE SECURITY DEFINER SET search_path = public AS $$
DECLARE g public.goals; v numeric;
BEGIN
  SELECT * INTO g FROM public.goals WHERE id = _goal;
  IF NOT FOUND THEN RETURN NULL; END IF;
  IF g.measure = 'manual' THEN
    SELECT sum(e.amount) INTO v FROM public.goal_entries e
    WHERE e.goal_id = g.id AND e.created_at >= _from AND e.created_at < _to
      AND (_users IS NULL OR e.user_id = ANY (_users));
    RETURN v;
  END IF;
  RETURN public.goals_metric_raw(g.company_id, g.metric, _from, _to, _users);
END; $$;

CREATE OR REPLACE FUNCTION public.goals_progress_for(_company uuid, _check boolean, _goal_ids uuid[])
RETURNS TABLE (goal_id uuid, period_id uuid, period_start date, period_end date, value numeric, weeks jsonb, contributions jsonb)
LANGUAGE plpgsql STABLE SECURITY DEFINER SET search_path = public AS $$
DECLARE
  g public.goals; p public.goal_periods; users uuid[]; w date; ws date; we date;
  today date := (public.goals_now() AT TIME ZONE 'America/Sao_Paulo')::date;
  manager boolean := CASE WHEN _check THEN public.goals_can_manage(_company) ELSE true END;
BEGIN
  FOR g IN SELECT * FROM public.goals x WHERE x.company_id = _company AND x.archived_at IS NULL
                AND (_goal_ids IS NULL OR x.id = ANY (_goal_ids)) ORDER BY x.created_at LOOP
    CONTINUE WHEN _check AND NOT public.goals_can_see(g.id);
    SELECT * INTO p FROM public.goal_periods gp WHERE gp.goal_id = g.id AND gp.closed_at IS NULL ORDER BY gp.starts_on DESC LIMIT 1;
    CONTINUE WHEN NOT FOUND;
    users := CASE WHEN g.scope = 'empresa' THEN NULL ELSE (SELECT array_agg(m.user_id) FROM public.goal_members m WHERE m.goal_id = g.id) END;
    goal_id := g.id; period_id := p.id; period_start := p.starts_on; period_end := p.ends_on;
    value := public.goals_value(g.id, public.goals_day_start(p.starts_on), public.goals_day_start(least(p.ends_on, today) + 1), users);
    weeks := '[]'::jsonb;
    w := date_trunc('week', p.starts_on)::date;
    WHILE w <= p.ends_on LOOP
      ws := greatest(w, p.starts_on); we := least(w + 6, p.ends_on);
      weeks := weeks || jsonb_build_object('startsOn', ws, 'endsOn', we, 'actual',
        CASE WHEN ws > today THEN NULL
             ELSE coalesce(public.goals_value(g.id, public.goals_day_start(ws), public.goals_day_start(least(we, today) + 1), users), 0) END);
      w := w + 7;
    END LOOP;
    IF manager OR g.scope = 'empresa' THEN
      SELECT coalesce(jsonb_agg(jsonb_build_object('userId', s.user_id, 'value', s.v) ORDER BY s.v DESC), '[]'::jsonb) INTO contributions
      FROM (
        SELECT u.user_id, public.goals_value(g.id, public.goals_day_start(p.starts_on), public.goals_day_start(least(p.ends_on, today) + 1), ARRAY[u.user_id]) AS v
        FROM (SELECT m.user_id FROM public.goal_members m WHERE m.goal_id = g.id AND g.scope <> 'empresa'
              UNION SELECT a.user_id FROM public.company_member_access a WHERE a.company_id = g.company_id AND g.scope = 'empresa') u
      ) s WHERE s.v IS NOT NULL AND s.v <> 0;
    ELSE
      contributions := '[]'::jsonb;
    END IF;
    RETURN NEXT;
  END LOOP;
END; $$;

CREATE OR REPLACE FUNCTION public.goals_progress(_goal_ids uuid[] DEFAULT NULL)
RETURNS TABLE (goal_id uuid, period_id uuid, period_start date, period_end date, value numeric, weeks jsonb, contributions jsonb)
LANGUAGE sql STABLE SECURITY DEFINER SET search_path = public AS $$
  SELECT * FROM public.goals_progress_for(public.current_company_id(), true, _goal_ids);
$$;

REVOKE ALL ON FUNCTION public.goals_value(uuid, timestamptz, timestamptz, uuid[]) FROM PUBLIC, anon, authenticated;

  public.goals_value(uuid, timestamptz, timestamptz, uuid[]),
```

```sql
CREATE OR REPLACE FUNCTION public.goals_apply_insight(_insight uuid)
RETURNS void LANGUAGE plpgsql SECURITY DEFINER SET search_path = public AS $$
DECLARE i public.goal_insights; g public.goals; kind text; target_goal uuid;
BEGIN
  SELECT * INTO i FROM public.goal_insights WHERE id = _insight FOR UPDATE;
  IF NOT FOUND OR NOT public.goals_can_manage(i.company_id) THEN RAISE EXCEPTION 'Sem permissão.' USING ERRCODE = '42501'; END IF;
  IF i.state <> 'pendente' OR i.kind <> 'sugestao' OR i.action IS NULL THEN RAISE EXCEPTION 'Sugestão já decidida ou sem ação.'; END IF;
  kind := i.action ->> 'type';
  target_goal := (i.action ->> 'goalId')::uuid;
  SELECT * INTO g FROM public.goals WHERE id = target_goal AND company_id = i.company_id FOR UPDATE;
  IF NOT FOUND THEN RAISE EXCEPTION 'Meta da sugestão não existe mais.'; END IF;
  IF kind = 'ajustar_alvo' THEN
    UPDATE public.goals SET target = (i.action ->> 'target')::numeric WHERE id = g.id;
  ELSIF kind = 'ajustar_prazo' THEN
    IF g.recurrence IS NOT NULL THEN RAISE EXCEPTION 'Metas recorrentes não têm prazo final.'; END IF;
    UPDATE public.goals SET ends_on = (i.action ->> 'endsOn')::date WHERE id = g.id;
    UPDATE public.goal_periods SET ends_on = (i.action ->> 'endsOn')::date WHERE goal_id = g.id AND closed_at IS NULL;
  ELSIF kind = 'mover_etapa' THEN
    IF NOT EXISTS (SELECT 1 FROM public.goal_stages s WHERE s.id = (i.action ->> 'stageId')::uuid AND s.company_id = i.company_id) THEN
      RAISE EXCEPTION 'Etapa não existe.'; END IF;
    UPDATE public.goals SET stage_id = (i.action ->> 'stageId')::uuid WHERE id = g.id;
  ELSE
    RAISE EXCEPTION 'Ação desconhecida: %', kind;
  END IF;
  UPDATE public.goal_insights SET state = 'aplicada', decided_by = auth.uid(), decided_at = now() WHERE id = i.id;
END; $$;

CREATE OR REPLACE FUNCTION public.goals_dismiss_insight(_insight uuid)
RETURNS void LANGUAGE plpgsql SECURITY DEFINER SET search_path = public AS $$
DECLARE i public.goal_insights;
BEGIN
  SELECT * INTO i FROM public.goal_insights WHERE id = _insight FOR UPDATE;
  IF NOT FOUND OR NOT public.goals_can_manage(i.company_id) THEN RAISE EXCEPTION 'Sem permissão.' USING ERRCODE = '42501'; END IF;
  IF i.state <> 'pendente' THEN RAISE EXCEPTION 'Sugestão já decidida.'; END IF;
  UPDATE public.goal_insights SET state = 'dispensada', decided_by = auth.uid(), decided_at = now() WHERE id = i.id;
END; $$;

CREATE OR REPLACE FUNCTION public.goals_roll_periods(_today date)
RETURNS integer LANGUAGE plpgsql SECURITY DEFINER SET search_path = public AS $$
DECLARE p record; v numeric; users uuid[]; closed integer := 0;
BEGIN
  FOR p IN SELECT gp.*, g.target, g.lower_is_better, g.recurrence, g.scope, g.starts_on AS goal_start, g.ends_on AS goal_end, g.archived_at
           FROM public.goal_periods gp JOIN public.goals g ON g.id = gp.goal_id
           WHERE gp.closed_at IS NULL AND gp.ends_on < _today FOR UPDATE OF gp LOOP
    users := CASE WHEN p.scope = 'empresa' THEN NULL ELSE (SELECT array_agg(m.user_id) FROM public.goal_members m WHERE m.goal_id = p.goal_id) END;
    v := public.goals_value(p.goal_id, public.goals_day_start(p.starts_on), public.goals_day_start(p.ends_on + 1), users);
    UPDATE public.goal_periods SET final_value = v, closed_at = now(),
      final_status = CASE
        WHEN v IS NOT NULL AND ((NOT p.lower_is_better AND v >= p.target) OR (p.lower_is_better AND v <= p.target)) THEN 'concluida'
        ELSE 'encerrada' END
      WHERE id = p.id;
    closed := closed + 1;
    IF p.recurrence IS NOT NULL AND p.archived_at IS NULL THEN
      INSERT INTO public.goal_periods (goal_id, starts_on, ends_on)
      SELECT p.goal_id, b.starts_on, b.ends_on FROM public.goals_period_bounds(p.recurrence, p.goal_start, NULL, p.ends_on + 1) b
      ON CONFLICT (goal_id, starts_on) DO NOTHING;
    END IF;
  END LOOP;
  RETURN closed;
END; $$;

REVOKE ALL ON FUNCTION public.goals_roll_periods(date) FROM PUBLIC, anon, authenticated;
GRANT EXECUTE ON FUNCTION public.goals_roll_periods(date) TO service_role;
REVOKE ALL ON FUNCTION public.goals_apply_insight(uuid), public.goals_dismiss_insight(uuid) FROM PUBLIC, anon;
GRANT EXECUTE ON FUNCTION public.goals_apply_insight(uuid), public.goals_dismiss_insight(uuid) TO authenticated;
```

```ts
import { supabase } from "@/integrations/supabase/client";
import { METRICS, type Goal, type GoalDraft, type GoalMetric, type GoalProgressRaw } from "./model";

export interface GoalStage {
  id: string;
  name: string;
  hue: number;
  position: number;
}
export type GoalAction =
  | { type: "ajustar_alvo"; goalId: string; target: number }
  | { type: "ajustar_prazo"; goalId: string; endsOn: string }
  | { type: "mover_etapa"; goalId: string; stageId: string };
export interface GoalInsight {
  id: string;
  kind: "resumo" | "atencao" | "sugestao" | "dica";
  goalId: string | null;
  body: string;
  action: GoalAction | null;
  state: "pendente" | "aplicada" | "dispensada";
  generatedOn: string;
}

export interface GoalRow {
  id: string; company_id: string; name: string; description: string | null; hue: number;
  measure: "automatica" | "manual"; metric: string | null; target: string | number; unit: string | null;
  lower_is_better: boolean; scope: "empresa" | "pessoa" | "grupo"; starts_on: string; ends_on: string | null;
  recurrence: "semanal" | "mensal" | null; stage_id: string | null; archived_at: string | null;
}
export interface ProgressRow {
  goal_id: string; period_id: string; period_start: string; period_end: string; value: string | number | null;
  weeks: Array<{ startsOn: string; endsOn: string; actual: string | number | null }>;
  contributions: Array<{ userId: string; value: string | number }>;
}

const num = (v: string | number | null) => (v === null ? null : Number(v));
// As novas tabelas ainda não estão nos tipos gerados do Supabase.
const db = supabase as unknown as { from: (t: string) => any; rpc: (f: string, a?: object) => any };

export function mapGoalRow(row: GoalRow, members: string[]): Goal {
  return {
    id: row.id, companyId: row.company_id, name: row.name, description: row.description, hue: row.hue,
    measure: row.measure, metric: row.metric as GoalMetric | null, target: Number(row.target), unit: row.unit,
    lowerIsBetter: row.lower_is_better, scope: row.scope, startsOn: row.starts_on, endsOn: row.ends_on,
    recurrence: row.recurrence, stageId: row.stage_id, archivedAt: row.archived_at, memberIds: members,
  };
}

export function mapProgressRow(row: ProgressRow): GoalProgressRaw {
  return {
    goalId: row.goal_id, periodId: row.period_id, periodStart: row.period_start, periodEnd: row.period_end,
    value: num(row.value),
    weeks: (row.weeks ?? []).map((w) => ({ startsOn: w.startsOn, endsOn: w.endsOn, actual: num(w.actual) })),
    contributions: (row.contributions ?? []).map((c) => ({ userId: c.userId, value: Number(c.value) })),
  };
}

export function draftToRow(draft: GoalDraft, companyId: string) {
  const automatic = draft.measure === "automatica";
  return {
    company_id: companyId,
    name: draft.name.trim(),
    description: draft.description.trim() || null,
    hue: draft.hue,
    measure: draft.measure,
    metric: automatic ? draft.metric : null,
    target: draft.target,
    unit: automatic ? null : draft.unit.trim(),
    lower_is_better: automatic && draft.metric ? METRICS[draft.metric].lowerIsBetter : false,
    scope: draft.scope,
    starts_on: draft.startsOn,
    ends_on: draft.deadline === "unico" ? draft.endsOn : null,
    recurrence: draft.deadline === "recorrente" ? draft.recurrence : null,
    stage_id: draft.stageId,
  };
}

function check<T>(result: { data: T; error: { message: string } | null }): T {
  if (result.error) throw new Error(result.error.message);
  return result.data;
}

async function setMembers(goalId: string, memberIds: string[]) {
  check(await db.from("goal_members").delete().eq("goal_id", goalId));
  if (memberIds.length)
    check(await db.from("goal_members").insert(memberIds.map((user_id) => ({ goal_id: goalId, user_id }))));
}

    const { error } = await db.from("goals").select("id").limit(1);
```

```ts
import { useCallback, useEffect, useMemo, useState } from "react";
import { useAuth } from "@/auth/AuthContext";
import { useTeamDirectory, type TeamMember } from "@/components/agenda/useTeamDirectory";
import { goalsApi, type GoalInsight, type GoalStage } from "./api";
import { buildProgress, todayInSaoPaulo, type Goal, type GoalProgress } from "./model";

export function useGoals() {
  const { company } = useAuth();
  const companyId = company?.id ?? null;
  const [ready, setReady] = useState<boolean | null>(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);
  const [goals, setGoals] = useState<Goal[]>([]);
  const [rawProgress, setRawProgress] = useState<Awaited<ReturnType<typeof goalsApi.progress>>>([]);
  const [stages, setStages] = useState<GoalStage[]>([]);
  const [insights, setInsights] = useState<GoalInsight[]>([]);
  const members: TeamMember[] = useTeamDirectory(true);

  const reload = useCallback(async () => {
    if (!companyId) return;
    setLoading(true);
    setError(null);
    try {
      const ok = await goalsApi.schemaReady();
      setReady(ok);
      if (!ok) return;
      const [g, p, s, i] = await Promise.all([
        goalsApi.list(companyId), goalsApi.progress(), goalsApi.stages(companyId), goalsApi.insights(companyId),
      ]);
      setGoals(g);
      setRawProgress(p);
      setStages(s);
      setInsights(i);
    } catch (e) {
      setError(e instanceof Error ? e.message : "Não foi possível carregar as metas.");
    } finally {
      setLoading(false);
    }
  }, [companyId]);

  useEffect(() => {
    void reload();
  }, [reload]);

  const progress = useMemo(() => {
    const today = todayInSaoPaulo();
    const map = new Map<string, GoalProgress>();
    for (const raw of rawProgress) {
      const goal = goals.find((g) => g.id === raw.goalId);
      if (goal) map.set(goal.id, buildProgress(goal, raw, today));
    }
    return map;
  }, [goals, rawProgress]);

  return { companyId, ready, loading, error, goals, progress, stages, insights, members, reload, actions: goalsApi };
}
```

```tsx
// src/components/goals/WaveProgress.tsx
import { useEffect, useState, type CSSProperties } from "react";
import type { GoalStatus } from "@/lib/goals/model";
import "./goals.css";

/**
 * Barra de progresso em ondas roxas. Duas ondas SVG deslizam em loop (só
 * transform) dentro de um preenchimento que sobe do 0 ao valor ao montar.
 * Com "reduzir movimento", tudo fica parado (regras em goals.css).
 */
export function WaveProgress({
  pct,
  status,
  label,
  size = "lg",
}: {
  pct: number;
  status: GoalStatus;
  label: string;
  size?: "lg" | "sm";
}) {
  const value = Math.round(Math.max(0, Math.min(100, pct)));
  const [shown, setShown] = useState(0);
  useEffect(() => {
    const frame = requestAnimationFrame(() => setShown(value));
    return () => cancelAnimationFrame(frame);
  }, [value]);

  return (
    <div
      role="progressbar"
      aria-valuemin={0}
      aria-valuemax={100}
      aria-valuenow={value}
      aria-valuetext={label}
      data-status={status}
      data-size={size}
      className="gw-bar"
    >
      <div className="gw-fill" style={{ "--gw-pct": `${shown}%` } as CSSProperties}>
        <svg className="gw-wave gw-wave-back" viewBox="0 0 200 20" preserveAspectRatio="none" aria-hidden>
          <path d="M0 10 Q 25 0 50 10 T 100 10 T 150 10 T 200 10 V 20 H 0 Z" />
        </svg>
        <svg className="gw-wave gw-wave-front" viewBox="0 0 200 20" preserveAspectRatio="none" aria-hidden>
          <path d="M0 12 Q 25 4 50 12 T 100 12 T 150 12 T 200 12 V 20 H 0 Z" />
        </svg>
      </div>
    </div>
  );
}
```

```tsx
// src/components/goals/GoalKanban.tsx
import { useState } from "react";
import { MoreHorizontal, Plus, Settings2 } from "lucide-react";
import { DropdownMenu, DropdownMenuContent, DropdownMenuItem, DropdownMenuTrigger } from "@/components/ui/dropdown-menu";
import { SegmentedTabs } from "@/components/layout/MobileSections";
import { useIsMobile } from "@/hooks/use-mobile";
import type { Goal, GoalProgress } from "@/lib/goals/model";
import type { GoalStage } from "@/lib/goals/api";
import { GoalCard } from "./GoalCard";
import { StageManager } from "./StageManager";

const NONE = "__none";

export function GoalKanban({
  goals, progress, stages, members, canManage, onMove, onOpen, onSaveStage, onRemoveStage,
}: {
  goals: Goal[];
  progress: Map<string, GoalProgress>;
  stages: GoalStage[];
  members: Array<{ id: string; name: string }>;
  canManage: boolean;
  onMove: (goalId: string, stageId: string | null) => void;
  onOpen: (goal: Goal) => void;
  onSaveStage: (stage: Partial<GoalStage> & { name: string }) => void;
  onRemoveStage: (id: string, moveTo: string | null) => void;
}) {
  const isMobile = useIsMobile();
  const [managing, setManaging] = useState(false);
  const [over, setOver] = useState<string | null>(null);
  const columns = [...stages.map((s) => ({ id: s.id, name: s.name, hue: s.hue })), { id: NONE, name: "Sem etapa", hue: 0 }];
  const [mobileColumn, setMobileColumn] = useState(columns[0].id);
  const visible = isMobile ? columns.filter((c) => c.id === mobileColumn) : columns;

  return (
    <div className="gl-kanban-wrap">
      <div className="mb-3 flex items-center justify-between gap-2">
        {isMobile ? (
          <SegmentedTabs label="Etapas" value={mobileColumn} onChange={setMobileColumn}
            tabs={columns.map((c) => ({ id: c.id, label: `${c.name} · ${goals.filter((g) => (g.stageId ?? NONE) === c.id).length}` }))} />
        ) : <span />}
        {canManage && (
          <button type="button" className="gl-ghost" onClick={() => setManaging(true)}>
            {stages.length ? <Settings2 className="h-4 w-4" aria-hidden /> : <Plus className="h-4 w-4" aria-hidden />}
            {stages.length ? "Etapas" : "Criar etapas"}
          </button>
        )}
      </div>
      <div className="gl-kanban" data-mobile={isMobile || undefined}>
        {visible.map((column) => {
          const items = goals.filter((g) => (g.stageId ?? NONE) === column.id);
          return (
            <section key={column.id} role="region" aria-label={column.name} className="gl-column" data-over={over === column.id || undefined}
              onDragOver={(e) => { if (!canManage) return; e.preventDefault(); setOver(column.id); }}
              onDragLeave={() => setOver((o) => (o === column.id ? null : o))}
              onDrop={(e) => {
                e.preventDefault();
                setOver(null);
                const id = e.dataTransfer.getData("text/plain");
                if (id) onMove(id, column.id === NONE ? null : column.id);
              }}>
              <h3 className="gl-column-title">
                {column.id !== NONE && <i style={{ background: `oklch(0.66 0.17 ${column.hue})` }} />}
                {column.name} <span>{items.length}</span>
              </h3>
              <div className="space-y-3">
                {items.map((goal) => (
                  <div key={goal.id} draggable={canManage} onDragStart={(e) => { e.dataTransfer.setData("text/plain", goal.id); e.dataTransfer.effectAllowed = "move"; }}>
                    <GoalCard goal={goal} progress={progress.get(goal.id)} members={members} onOpen={onOpen}
                      footer={canManage ? (
                        <DropdownMenu>
                          <DropdownMenuTrigger asChild>
                            <button type="button" className="gl-card-move" aria-label={`Mover ${goal.name}`}>
                              <MoreHorizontal className="h-4 w-4" aria-hidden />
                            </button>
                          </DropdownMenuTrigger>
                          <DropdownMenuContent align="end">
                            {columns.filter((c) => c.id !== (goal.stageId ?? NONE)).map((c) => (
                              <DropdownMenuItem key={c.id} onSelect={() => onMove(goal.id, c.id === NONE ? null : c.id)}>{c.name}</DropdownMenuItem>
                            ))}
                          </DropdownMenuContent>
                        </DropdownMenu>
                      ) : null} />
                  </div>
                ))}
                {items.length === 0 && <p className="gl-empty">Nenhuma meta aqui.</p>}
              </div>
            </section>
          );
        })}
      </div>
      {managing && <StageManager stages={stages} onClose={() => setManaging(false)} onSave={onSaveStage} onRemove={onRemoveStage} />}
    </div>
  );
}
```

```tsx
// src/components/goals/StageManager.tsx
import { useState } from "react";
import { ArrowDown, ArrowUp, Trash2 } from "lucide-react";
import { Sheet, SheetContent, SheetTitle } from "@/components/ui/sheet";
import type { GoalStage } from "@/lib/goals/api";

export function StageManager({
  stages, onClose, onSave, onRemove,
}: {
  stages: GoalStage[];
  onClose: () => void;
  onSave: (stage: Partial<GoalStage> & { name: string }) => void;
  onRemove: (id: string, moveTo: string | null) => void;
}) {
  const [name, setName] = useState("");
  const swap = (index: number, dir: -1 | 1) => {
    const other = stages[index + dir];
    if (!other) return;
    onSave({ ...stages[index], position: other.position });
    onSave({ ...other, position: stages[index].position });
  };
  return (
    <Sheet open onOpenChange={(open) => !open && onClose()}>
      <SheetContent side="right" className="w-[94vw] max-w-[420px] space-y-4">
        <SheetTitle>Etapas das metas</SheetTitle>
        <p className="text-sm text-muted-foreground">As colunas do kanban. Só você define quais são.</p>
        <form className="flex gap-2" onSubmit={(e) => { e.preventDefault(); if (!name.trim()) return; onSave({ name: name.trim(), position: stages.length }); setName(""); }}>
          <input className="h-10 min-w-0 flex-1 rounded-full border border-border bg-transparent px-4 text-sm" placeholder="Ex.: Planejada" maxLength={40}
            value={name} onChange={(e) => setName(e.target.value)} aria-label="Nome da etapa" />
          <button type="submit" className="lq-primary">Adicionar</button>
        </form>
        <ul className="space-y-2">
          {stages.map((stage, index) => (
            <li key={stage.id} className="flex items-center gap-2 rounded-2xl border border-border px-3 py-2">
              <input className="min-w-0 flex-1 bg-transparent text-sm" defaultValue={stage.name} maxLength={40} aria-label={`Renomear ${stage.name}`}
                onBlur={(e) => e.target.value.trim() && e.target.value !== stage.name && onSave({ ...stage, name: e.target.value.trim() })} />
              <button type="button" aria-label={`Subir ${stage.name}`} onClick={() => swap(index, -1)}><ArrowUp className="h-4 w-4" /></button>
              <button type="button" aria-label={`Descer ${stage.name}`} onClick={() => swap(index, 1)}><ArrowDown className="h-4 w-4" /></button>
              <button type="button" aria-label={`Excluir ${stage.name}`}
                onClick={() => {
                  const others = stages.filter((s) => s.id !== stage.id);
                  const target = others.length ? window.prompt(`Mover as metas de "${stage.name}" para qual etapa?\n${others.map((s) => s.name).join(", ")}\n(deixe vazio para "Sem etapa")`) : "";
                  if (target === null) return;
                  onRemove(stage.id, others.find((s) => s.name.toLowerCase() === target.trim().toLowerCase())?.id ?? null);
                }}><Trash2 className="h-4 w-4" /></button>
            </li>
          ))}
        </ul>
      </SheetContent>
    </Sheet>
  );
}
```

```tsx
import { useState } from "react";
import { useIsMobile } from "@/hooks/use-mobile";
import { formatGoalValue, type Goal, type GoalProgress, type GoalWeek } from "@/lib/goals/model";

const short = (date: string) => date.split("-").reverse().slice(0, 2).join("/");

function Cell({ goal, week }: { goal: Goal; week: GoalWeek }) {
  const actual = week.actual === null ? "—" : `${formatGoalValue(week.actual, goal)} / ${formatGoalValue(week.expected, goal)}`;
  return (
    <div className="gl-week-cell" data-status={week.status ?? "futura"}>
      <span className="gl-week-range">{short(week.startsOn)}–{short(week.endsOn)}</span>
      <strong>{actual}</strong>
    </div>
  );
}

export function GoalWeekView({
  goals, progress, onOpen,
}: { goals: Goal[]; progress: Map<string, GoalProgress>; onOpen: (goal: Goal) => void }) {
  const isMobile = useIsMobile();
  const [selected, setSelected] = useState(goals[0]?.id ?? "");
  if (!goals.length) return <p className="gl-empty">Nenhuma meta para mostrar.</p>;

  if (isMobile) {
    const goal = goals.find((x) => x.id === selected) ?? goals[0];
    const weeks = progress.get(goal.id)?.weeks ?? [];
    return (
      <div className="space-y-3">
        <select className="h-11 w-full rounded-2xl border border-border bg-transparent px-4 text-sm" value={goal.id}
          onChange={(e) => setSelected(e.target.value)} aria-label="Meta">
          {goals.map((x) => <option key={x.id} value={x.id}>{x.name}</option>)}
        </select>
        <div className="gl-week-strip">{weeks.map((w) => <Cell key={w.startsOn} goal={goal} week={w} />)}</div>
      </div>
    );
  }

  return (
    <div className="space-y-2" role="table" aria-label="Metas por semana">
      {goals.map((goal) => (
        <div key={goal.id} role="row" className="gl-week-row">
          <button type="button" role="rowheader" className="gl-week-name" onClick={() => onOpen(goal)}>{goal.name}</button>
          <div className="gl-week-strip">
            {(progress.get(goal.id)?.weeks ?? []).map((w) => <Cell key={w.startsOn} goal={goal} week={w} />)}
          </div>
        </div>
      ))}
    </div>
  );
}
```

```tsx
// src/components/goals/GoalListView.tsx
import { useMemo, useState } from "react";
import { Search } from "lucide-react";
import { formatGoalValue, METRICS, STATUS_LABEL, type Goal, type GoalProgress, type GoalStatus } from "@/lib/goals/model";
import { StatusBadge } from "./GoalCard";

const FILTERS: GoalStatus[] = ["no_ritmo", "em_risco", "atrasada", "concluida", "sem_dados"];
const fold = (s: string) => s.normalize("NFD").replace(/\p{Diacritic}/gu, "").toLowerCase();

export function GoalListView({
  goals, progress, members, onOpen,
}: {
  goals: Goal[];
  progress: Map<string, GoalProgress>;
  members: Array<{ id: string; name: string }>;
  onOpen: (goal: Goal) => void;
}) {
  const [query, setQuery] = useState("");
  const [status, setStatus] = useState<GoalStatus | null>(null);
  const [person, setPerson] = useState("");
  const rows = useMemo(
    () => goals.filter((goal) => {
      if (query && !fold(goal.name).includes(fold(query))) return false;
      if (status && progress.get(goal.id)?.status !== status) return false;
      if (person && !goal.memberIds.includes(person)) return false;
      return true;
    }),
    [goals, progress, query, status, person],
  );
  return (
    <div className="space-y-3">
      <div className="flex flex-wrap items-center gap-2">
        <label className="relative min-w-0 flex-1 basis-56">
          <Search className="pointer-events-none absolute left-3 top-1/2 h-4 w-4 -translate-y-1/2 text-muted-foreground" aria-hidden />

            <option value="">Todas as pessoas</option>
            {members.map((m) => <option key={m.id} value={m.id}>{m.name}</option>)}
          </select>
        )}
      </div>
      <div className="flex gap-2 overflow-x-auto scrollbar-none">
        {FILTERS.map((s) => (
          <button key={s} type="button" aria-pressed={status === s} className="gl-filter" onClick={() => setStatus(status === s ? null : s)}>
            {STATUS_LABEL[s]}
          </button>
        ))}
      </div>
      <ul className="divide-y divide-border rounded-2xl border border-border">
        {rows.map((goal) => {

            <li key={goal.id}>
              <button type="button" className="flex w-full items-center gap-3 px-4 py-3 text-left" onClick={() => onOpen(goal)}>

        {rows.length === 0 && <li className="px-4 py-6 text-center text-sm text-muted-foreground">Nenhuma meta com esse filtro.</li>}
      </ul>
    </div>
  );
}
```

```ts
import { z } from "zod";
import { resolveLumeLlmConfig } from "@/lib/lume/config.server";
import { mapGoalRow, mapProgressRow, type GoalAction, type GoalRow, type ProgressRow } from "./api";
import { buildProgress, formatGoalValue, METRICS, STATUS_LABEL } from "./model";

export interface GoalsContext {
  today: string;
  goals: Array<{
    id: string; name: string; indicator: string; target: string; value: string; expected: string; status: string;
    weeks: Array<{ range: string; actual: string; expected: string }>;
    people: Array<{ userId: string; name: string; value: string }>;
  }>;
  stages: Array<{ id: string; name: string }>;
  members: Array<{ id: string; name: string }>;
}

const Analysis = z.object({
  resumo: z.string().max(400).catch(""),
  atencao: z.array(z.object({ goalId: z.string(), body: z.string().max(400) })).catch([]),
  sugestoes: z.array(z.object({
    goalId: z.string(),
    body: z.string().max(400),
    action: z.object({ type: z.string(), target: z.number().positive().optional(), endsOn: z.string().optional(), stageId: z.string().optional() }).nullable().optional(),
  })).catch([]),
  dicas: z.array(z.object({ userId: z.string(), body: z.string().max(400) })).catch([]),
});

export function parseGoalsAnalysis(raw: unknown, ctx: GoalsContext) {
  let value = raw;
  if (typeof raw === "string") {
    try { value = JSON.parse(raw); } catch { value = {}; }
  }
  const parsed = Analysis.safeParse(value);
  const data = parsed.success ? parsed.data : { resumo: "", atencao: [], sugestoes: [], dicas: [] };
  const goalIds = new Set(ctx.goals.map((g) => g.id));
  const stageIds = new Set(ctx.stages.map((s) => s.id));
  const memberIds = new Set(ctx.members.map((m) => m.id));
  const toAction = (goalId: string, a: z.infer<typeof Analysis>["sugestoes"][number]["action"]): GoalAction | null | undefined => {
    if (!a || a.type === "foco_semana") return null;
    if (a.type === "ajustar_alvo" && a.target) return { type: "ajustar_alvo", goalId, target: a.target };
    if (a.type === "ajustar_prazo" && a.endsOn && /^\d{4}-\d{2}-\d{2}$/.test(a.endsOn) && a.endsOn >= ctx.today) return { type: "ajustar_prazo", goalId, endsOn: a.endsOn };
    if (a.type === "mover_etapa" && a.stageId && stageIds.has(a.stageId)) return { type: "mover_etapa", goalId, stageId: a.stageId };
    return undefined; // ação inválida: descarta a sugestão
  };
  return {
    resumo: data.resumo.trim(),
    atencao: data.atencao.filter((a) => goalIds.has(a.goalId)),
    sugestoes: data.sugestoes.flatMap((s) => {
      if (!goalIds.has(s.goalId)) return [];
      const action = toAction(s.goalId, s.action);
      return action === undefined ? [] : [{ goalId: s.goalId, body: s.body, action }];
    }),
    dicas: data.dicas.filter((d) => memberIds.has(d.userId)),
  };
}

const SYSTEM = `Você é a Lume, assistente de metas de uma equipe de vendas e atendimento.
Responda SEMPRE em JSON com as chaves: resumo (até 2 frases), atencao [{goalId, body}],
sugestoes [{goalId, body, action}] e dicas [{userId, body}].
action é um destes: {"type":"ajustar_alvo","target":número}, {"type":"ajustar_prazo","endsOn":"AAAA-MM-DD"},
{"type":"mover_etapa","stageId":"id de uma etapa listada"} ou {"type":"foco_semana"} (sem alteração).
Use só números presentes no contexto. Seja direto, em português do Brasil, sem jargão.
dicas: no máximo uma por pessoa, só sobre as metas dela, com algo que dá para fazer hoje.`;

async function callModel(messages: Array<{ role: string; content: string }>, fetchImpl: typeof fetch, json: boolean) {
  const config = resolveLumeLlmConfig();
  if (!config) throw new Error("A IA Lume ainda não está configurada. Falta a chave de API.");
  const response = await fetchImpl(config.endpoint, {
    method: "POST",
    headers: { Authorization: `Bearer ${config.apiKey}`, "Content-Type": "application/json" },
    body: JSON.stringify({
      model: config.model, messages, max_completion_tokens: 1200,
      ...(json ? { response_format: { type: "json_object" } } : {}),
    }),
    signal: AbortSignal.timeout(45_000),
  });
  if (!response.ok) throw new Error("A Lume não conseguiu analisar as metas agora.");
  const body = (await response.json()) as { choices?: Array<{ message?: { content?: string } }> };
  return body.choices?.[0]?.message?.content ?? "";
}

export async function analyzeGoals(ctx: GoalsContext, fetchImpl: typeof fetch = fetch) {
  const content = await callModel(
    [{ role: "system", content: SYSTEM }, { role: "user", content: `Hoje é ${ctx.today}. Contexto:\n${JSON.stringify(ctx)}` }],
    fetchImpl,
    true,
  );
  return parseGoalsAnalysis(content, ctx);
}

export async function askGoals(question: string, ctx: GoalsContext, fetchImpl: typeof fetch = fetch) {

      { role: "user", content: `Hoje é ${ctx.today}. Metas:\n${JSON.stringify(ctx)}\n\nPergunta: ${question.slice(0, 1000)}` },
    ],
    fetchImpl,
    false,
  );
  return { answer: answer.trim() || "Não consegui responder agora." };
}

type SupabaseLike = { from: (t: string) => any; rpc: (f: string, a?: object) => any };

export async function loadGoalsContext(client: SupabaseLike, companyId: string, today: string, opts: { service: boolean }): Promise<GoalsContext> {
  const rows: GoalRow[] = (await client.from("goals").select("*").eq("company_id", companyId).is("archived_at", null)).data ?? [];
  const links: Array<{ goal_id: string; user_id: string }> = rows.length
    ? (await client.from("goal_members").select("goal_id,user_id").in("goal_id", rows.map((r) => r.id))).data ?? [] : [];
  const progressRows: ProgressRow[] = (opts.service
    ? await client.rpc("goals_progress_for", { _company: companyId, _check: false, _goal_ids: null })
    : await client.rpc("goals_progress", {})).data ?? [];
  const stages: Array<{ id: string; name: string }> = (await client.from("goal_stages").select("id,name").eq("company_id", companyId)).data ?? [];
  const people: Array<{ id: string; display_name: string | null }> = (await client.from("profiles").select("id,display_name").eq("company_id", companyId)).data ?? [];
  const members = people.map((p) => ({ id: p.id, name: p.display_name ?? "Sem nome" }));
  const goals = rows.flatMap((row) => {
    const goal = mapGoalRow(row, links.filter((l) => l.goal_id === row.id).map((l) => l.user_id));
    const raw = progressRows.find((p) => p.goal_id === row.id);
    if (!raw) return [];
    const p = buildProgress(goal, mapProgressRow(raw), today);
    return [{
      id: goal.id, name: goal.name,
      indicator: goal.measure === "automatica" && goal.metric ? METRICS[goal.metric].label : `À mão (${goal.unit})`,
      target: formatGoalValue(goal.target, goal), value: formatGoalValue(p.value, goal),
      expected: formatGoalValue(p.expected, goal), status: STATUS_LABEL[p.status],
      weeks: p.weeks.filter((w) => w.actual !== null).map((w) => ({ range: `${w.startsOn}..${w.endsOn}`, actual: formatGoalValue(w.actual, goal), expected: formatGoalValue(w.expected, goal) })),
      people: p.contributions.map((c) => ({ userId: c.userId, name: members.find((m) => m.id === c.userId)?.name ?? "ex-membro", value: formatGoalValue(c.value, goal) })),
    }];
  });
  return { today, goals, stages, members };
}
```

```ts
// src/lib/goals/tick.server.ts
import { analyzeGoals, loadGoalsContext } from "./ai.server";
import { mapGoalRow, mapProgressRow, type GoalRow, type ProgressRow } from "./api";
import { buildProgress } from "./model";

type SupabaseLike = { from: (t: string) => any; rpc: (f: string, a?: object) => any };

/**
 * Uma passada por dia: fecha/abre períodos, grava a foto de cada meta e
 * substitui a análise da Lume do dia. Idempotente no mesmo dia: fotos têm
 * chave (meta, período, dia) e a análise do dia é apagada antes de gravar.
 */
export async function runGoalsTick(admin: SupabaseLike, opts: { today: string; analyze?: typeof analyzeGoals }) {
  const analyze = opts.analyze ?? analyzeGoals;
  const result = { companies: 0, snapshots: 0, closed: 0, analyzed: 0, failures: 0 };
  const rolled = await admin.rpc("goals_roll_periods", { _today: opts.today });
  result.closed = Number(rolled.data ?? 0);

  const all: GoalRow[] = (await admin.from("goals").select("*").is("archived_at", null)).data ?? [];
  const companies = [...new Set(all.map((g) => g.company_id))];
  for (const companyId of companies) {
    result.companies += 1;
    try {
      const rows = all.filter((g) => g.company_id === companyId);
      const links: Array<{ goal_id: string; user_id: string }> = (await admin.from("goal_members").select("goal_id,user_id").in("goal_id", rows.map((r) => r.id))).data ?? [];
      const progress: ProgressRow[] = (await admin.rpc("goals_progress_for", { _company: companyId, _check: false, _goal_ids: null })).data ?? [];
      const snapshots = progress.flatMap((raw) => {
        const row = rows.find((r) => r.id === raw.goal_id);
        if (!row) return [];
        const goal = mapGoalRow(row, links.filter((l) => l.goal_id === row.id).map((l) => l.user_id));
        const p = buildProgress(goal, mapProgressRow(raw), opts.today);
        return [{ goal_id: goal.id, period_id: p.periodId, day: opts.today, value: p.value, expected: p.expected, status: p.status }];
      });
      if (snapshots.length) {
        await admin.from("goal_snapshots").upsert(snapshots, { onConflict: "goal_id,period_id,day" });
        result.snapshots += snapshots.length;
      }
      const ctx = await loadGoalsContext(admin, companyId, opts.today, { service: true });
      const analysis = await analyze(ctx);
      await admin.from("goal_insights").delete().eq("company_id", companyId).eq("generated_on", opts.today);
      const insights = [
        ...(analysis.resumo ? [{ kind: "resumo", goal_id: null, user_id: null, body: analysis.resumo, action: null }] : []),
        ...analysis.atencao.map((a) => ({ kind: "atencao", goal_id: a.goalId, user_id: null, body: a.body, action: null })),
        ...analysis.sugestoes.map((s) => ({ kind: "sugestao", goal_id: s.goalId, user_id: null, body: s.body, action: s.action })),
        ...analysis.dicas.map((d) => ({ kind: "dica", goal_id: null, user_id: d.userId, body: d.body, action: null })),
      ].map((i) => ({ ...i, company_id: companyId, generated_on: opts.today, state: "pendente" }));
      if (insights.length) await admin.from("goal_insights").insert(insights);
      result.analyzed += 1;
    } catch (error) {
      result.failures += 1;
      console.error("[goals-tick]", { companyId: companyId.slice(0, 8), error: error instanceof Error ? error.message : "erro" });
    }
  }
  return result;
}
```

```tsx
// ============================================================================
// POST /api/public/hooks/goals-tick — chamado 1x por dia pelo pg_cron.
// Mesmo padrão do followup-tick: segredo (GOALS_TICK_SECRET ou cofre),
// comparação segura, corpo vazio estrito, limite de taxa e trava global.
// ============================================================================
import { createFileRoute } from "@tanstack/react-router";
import { supabaseAdmin } from "@/integrations/supabase/client.server";
import { correlationId, rateLimit, releaseLock, safeEqualSecret, tryAcquireLock } from "@/lib/runtime/HookSecurity.server";
import { getHookSecret } from "@/lib/runtime/HookSecretVault.server";
import { todayInSaoPaulo } from "@/lib/goals/model";
import { runGoalsTick } from "@/lib/goals/tick.server";

const LOCK_KEY = "goals-tick:global";

export const Route = createFileRoute("/api/public/hooks/goals-tick")({
  server: {
    handlers: {
      POST: async ({ request }: { request: Request }) => {
        const cid = correlationId();
        const expected = (await getHookSecret("goals_tick_secret")) ?? process.env.GOALS_TICK_SECRET ?? null;
        if (!expected) return Response.json({ ok: false, error: "unavailable" }, { status: 503 });
        if (!safeEqualSecret(request.headers.get("x-goals-tick-secret") ?? "", expected))
          return Response.json({ ok: false, error: "unauthorized" }, { status: 401 });
        const raw = await request.text().catch(() => "");
        if (raw.length > 512) return Response.json({ ok: false, error: "payload_too_large" }, { status: 413 });
        if (raw.trim() && raw.trim() !== "{}") return Response.json({ ok: false, error: "invalid_body" }, { status: 400 });
        if (!rateLimit(LOCK_KEY, 6, 60_000).allowed) return Response.json({ ok: false, error: "rate_limited" }, { status: 429 });
        if (!tryAcquireLock(LOCK_KEY)) return Response.json({ ok: false, error: "busy" }, { status: 409 });
        try {
          const result = await runGoalsTick(supabaseAdmin as never, { today: todayInSaoPaulo() });
          console.info("[goals-tick]", { cid, ...result });
          return Response.json({ ok: true, ...result });
        } finally {
          releaseLock(LOCK_KEY);
        }
      },
    },
  },
});
```

Conferir em `HookSecurity.server.ts` as assinaturas reais de `rateLimit(key, limit, windowMs)` (retorna `{ allowed }`) e `tryAcquireLock(key, ttl?)` (retorna `boolean`) antes de rodar; o `followup-tick` usa exatamente essas chamadas.

```tsx
        </ul>
      )}

      <form className="gl-lume-ask" onSubmit={(e) => { e.preventDefault(); void ask(); }}>
        <input aria-label="Pergunte à Lume sobre as metas" placeholder="Pergunte à Lume sobre as metas…" value={question}
          maxLength={1000} onChange={(e) => setQuestion(e.target.value)} />
        <button type="submit" aria-label="Enviar pergunta" disabled={asking || !question.trim()}>
          {asking ? <Loader2 className="h-4 w-4 animate-spin" aria-hidden /> : <ArrowUp className="h-4 w-4" aria-hidden />}
        </button>
      </form>
      {answer && <p className="mt-3 text-sm leading-relaxed text-foreground/90">{answer}</p>}
    </section>
  );
}
```
